# 시간유적 (Time Ruins)

한국사 시대를 걸어 다니며 유물과 흔적을 조사하는 **탐험 어드벤처**.
전투도, 적도, 체력도 없다. 발견과 이동만 있다.

> "예전에 이곳에 사람들이 살았고, 그 흔적이 아직 남아 있다."

## 컨셉

1997년에 출시된 한국사 CD-ROM 교육용 PC 게임을 2026년에 웹으로 다시 만든 것 같은 화면을 목표로 한다.

- **Fallout 1** — 거친 90년대 PC 게임의 질감, 바랜 색, 디더링
- **Age of Empires 1** — 고정 등각(Isometric) 시점, 작은 캐릭터와 넓은 세계
- **대항해시대 (KOEI)** — 황동 테두리의 장식적인 UI, 세피아 삽화 톤
- **수채화풍 배경** — 번진 물감 얼룩과 종이 결

## 시대

| # | 시대 | 배경 | 조사 대상 |
|---|------|------|-----------|
| 1 | 신석기 시대 | 한반도 강가 마을 | 빗살무늬 토기 조각 · 간석기 · 불탄 나무 조각 |
| 2 | 청동기 시대 | 고인돌 제단 | 비파형 동검 조각 · 청동 방울 · 제단 문양 |
| 3 | 조선 시대 | 한양 외곽 마을 (밤) | 어사패 · 낡은 문서 · 장승의 문양 |

각 시대의 유물 3개를 모두 조사하면 **시간의 문**(고인돌)이 깨어나고, 다음 시대로 이동할 수 있다.

## 조작

| 키 | 동작 |
|----|------|
| `W` `A` `S` `D` / 방향키 | 이동 |
| `Shift` | 달리기 |
| `E` | 조사 / 획득 / 시대 이동 |
| `H` | 이정표 (가장 가까운 목표의 방향과 거리) |
| 마우스 클릭 | 해당 위치로 이동 |

WASD 입력이 항상 마우스 이동보다 우선한다.

### 미니맵

우측 상단에 등각 화면과 같은 방향으로 회전한 지도가 있다.
강과 연못, 건물, 아직 조사하지 않은 유물(깜빡이는 마름모),
시간의 문(원)이 표시된다.

### 이정표

`H` 를 누르거나 버튼을 클릭하면 플레이어 옆에 나무 이정표가 세워지고,
화면 아래에 목표의 방향 · 거리 · 방위가 표시된다.
자동 이동은 하지 않는다. 약 9초 후 사라진다.

## 기술

- **단일 `index.html`** — 외부 에셋 없음. `file://` 로 직접 열어도 실행된다.
- **Three.js** (CDN) — 모든 3D 모델을 기본 geometry 조합으로 코드에서 생성
- **저해상도 렌더 타겟** → 후처리 셰이더 → CSS `image-rendering: pixelated` 확대
- **후처리 셰이더** — 세피아 그레이딩, 4x4 Bayer 디더링, 필름 그레인, 비네팅, 색수차, 종이 질감, 시대 전환 글리치
- **Web Audio API** — 바람 · 물소리 · 북 · 국악 5음 음계 선율 · 환경음을 시대별로 전부 합성 (음원 파일 없음)

## 실행

```bash
# 그냥 파일을 열어도 된다
open index.html

# 또는 로컬 서버
python3 -m http.server 8000
```

개발 중에는 `index.html?era=1` / `?era=2` 로 특정 시대부터 시작할 수 있다.

## 배포 (Vercel)

정적 사이트이므로 빌드 과정이 없다.

```bash
vercel --prod
```

또는 GitHub 저장소를 Vercel 에 연결하면 푸시할 때마다 자동 배포된다.
Framework Preset 은 **Other**, Build Command 와 Output Directory 는 비워 둔다.

## 코드 구조

`index.html` 안의 스크립트는 다음 순서로 나뉘어 있다.

```
GAME STATE        시대 정의 (색 / 조명 / 안개 / 능선 / 그레이딩)
AUDIO             Web Audio 합성, 시대별 사운드 설정표
NOISE / TERRAIN   value noise, fbm, 지형 높이, 절차적 텍스처
POST PROCESSING   저해상도 렌더 타겟 + 90년대 느낌 셰이더
THREE INIT        렌더러 / 등각 카메라
INPUT             키보드 / 마우스
MATERIAL HELPERS  기본 도형 조합 헬퍼
UI / INTERACTION  조사, 인벤토리, 메시지
PLAYER            로우폴리 인물 + 걷기 애니메이션
CAMERA            고정 등각 추적
WORLD             지면, 배경판, 안개, 먼지, 풀, 길, 연못
MINIMAP / HINT    미니맵, 이정표
ERA BUILD         시대별 장면 구성
GAME LOOP
```

### 렌더링에서 신경 쓴 것

- **직교 카메라의 스펙큘러** — 시선 방향이 화면 전체에서 같기 때문에 매끈한 수면은
  판 전체가 균일하게 하얗게 타버린다. 물은 일부러 거칠게(`roughness` 0.8 이상) 두고,
  반짝임은 발광 판과 잔물결로 따로 만든다.
- **텍스처 이중 감산** — 오브젝트 텍스처는 재질의 `color` 와 곱해지므로 거의 흰 바탕에
  어두운 결만 그린다. 색을 가진 텍스처는 지면용 하나뿐이다.
- **인스턴싱** — 풀 · 자갈 수천 개는 `InstancedMesh` 로 묶어 드로우콜을 줄인다.

시대별 색감은 `AGE_DATA`, 질감 팔레트는 `TEX_PALETTE`, 사운드는 `AudioSystem.ERA_SOUND` 에서 한 곳에 모아 조정할 수 있다.
