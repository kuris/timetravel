# 시간유적 (Time Ruins)

한국사 시대를 걸어 다니며 유물과 흔적을 조사하는 **탐험 어드벤처**.
전투도, 적도, 체력도 없다. 발견과 이동만 있다.

> "예전에 이곳에 사람들이 살았고, 그 흔적이 아직 남아 있다."

## 컨셉

1997년에 출시된 한국사 CD-ROM 교육용 PC 게임을 2026년에 웹으로 다시 만든 것 같은 화면을 목표로 한다.

- **Fallout 1** — 거친 90년대 PC 게임의 질감, 바랜 색, 디더링
- **Age of Empires 1** — 고정 등각(Isometric) 시점, 작은 캐릭터와 넓은 세계
- **대항해시대 (KOEI)** — 황동 테두리의 장식적인 UI, 세피아 삽화 톤
- **수채화풍 배경** — 번진 물감 얼룩과 종이 결

## 시대

| # | 시대 | 배경 | 조사 대상 |
|---|------|------|-----------|
| 1 | 신석기 시대 | 한반도 강가 **빈 땅** | 빗살무늬 토기 조각 · 간석기 · 불탄 나무 조각 |
| 2 | 청동기 시대 | 고인돌 제단과 논 | 비파형 동검 조각 · 청동 방울 · 제단 문양 |
| 3 | 삼국시대 | 낙동강 유역의 마을 | 명문 기와 · 목간 · 성벽 각자 |
| 4 | 조선 시대 | 한양 외곽 마을 (해질녘) | 어사패 · 낡은 문서 · 장승의 문양 |
| 5 | 1970년대 | 시골 마을 | 공사 기록 · 낡은 수첩 · 멈춘 공사 |
| 6 | 2000년대 | 한강변 신도시 (초저녁) | 발굴 보고서 · 발굴 구덩이 · 안내판 |

### 여섯 시대에 걸쳐 마을은 하나뿐이다

남의 마을은 어디에도 없다. 여섯 시대 전부 그렇다.
집도 상가도 아파트도 놓지 않는다. 화면에 선 건물은 **플레이어가 세운 것뿐**이다.

시대가 남기는 것은 사는 곳이 아니라 **땅의 흔적**이다.

| 시대 | 남아 있는 것 |
|------|--------------|
| 신석기 | 오래된 조개더미 · 불탄 그루터기 · 고인돌 |
| 청동기 | 제단 · 선돌 열 · 고인돌 떼 · 제사장 한 사람 |
| 삼국 | 토성(그 돌 앞에서만 바깥으로 꺾인다) · 성문 · 고분 |
| 조선 | 장승 셋 · 연못과 나무다리 · 등불 몇 개 |
| 1970 | 신작로 · 전봇대와 전선 · 멈춘 공사 |
| 2000 | 길과 인도 · 가로등 · 문화재 울타리 · 발굴 구덩이 |

그래서 시대가 바뀌어도 "내 마을"은 끊기지 않는다.
신석기에 세운 움집 자리에 청동기 집이 서고, 삼국의 기와집이 서고,
2000년에는 그 자리에 상가가 선다. 여섯 시대를 통과하는 마을은 하나뿐이다.

### 시작 — 아무것도 없는 땅

첫 시대는 마을이 아니라 **빈 강가**다. 집도 길도 밭도 없다.
같이 도착한 장로와 동행 둘, 그리고 강과 숲과 바위뿐이다.
쓰러진 나무와 돌을 주워 원하는 자리에 서서 첫 집을 세우는 것으로 마을이 시작된다.
(Age of Empires 1 의 시작을 따른다.)

땅에 남은 사람의 자취는 셋뿐이고, 셋 다 **누가 지은 것이 아니라 남겨진 것**이다.
오래된 조개더미, 불탄 그루터기, 그리고 고인돌.

마을 발전도가 목표치에 닿으면 **시간의 문**(고인돌)이 깨어나고, 다음 시대로 이동할 수 있다.
유물 3개는 진급 조건이 아니라 이야기이자 재원이다 (조사하면 나무·돌·발전도가 들어온다).

### 이야기 — 그 돌은 왜 거기 있나

한 마을의 선사시대부터의 비밀을 따라가는 미스터리다.
같은 강가, 같은 자리에 선 돌 하나를 두고 시대마다 흔적이 쌓인다.

| 시대 | 드러나는 것 |
|------|-------------|
| 신석기 | 마을이 한 번 불탔다. 그런데 한 자리만 타지 않았다 |
| 청동기 | 날을 일부러 부러뜨린 동검. 제단 문양의 한가운데 원은 하늘이 아니라 땅을 가리킨다 |
| 삼국 | 성을 쌓으며 그 돌만 피해 벽을 꺾었다. 목간의 마지막 줄만 글씨가 다르다 |
| 조선 | 관아 기록의 금기. 장승 셋이 모두 같은 곳을 본다 |
| 1970 | 안길 공사가 멈췄다. 사유란은 비어 있다 |
| 2000 | 발굴 구덩이 맨 아래층에서 아이 하나가 나온다 |
| 조선 | 관아 기록에 그 돌을 건드리지 말라는 줄이 끼어 있다 |

여섯 시대의 사람들이 차례로 그 자리를 비껴갔다.
아무도 기억하지 못했지만, 아무도 잊지 않았다.

## 조작

| 키 | 동작 |
|----|------|
| `W` `A` `S` `D` / 방향키 | 이동 |
| `Shift` | 달리기 |
| `E` | 조사 / 베기 · 캐기 / 짓기 / 시대 이동 |
| `H` | 이정표 (가장 가까운 목표의 방향과 거리) |
| 마우스 클릭 | 해당 위치로 이동 |

WASD 입력이 항상 마우스 이동보다 우선한다.

### 몸으로 하는 일 — 채집과 건설

재료가 손만 대면 사라지고 건물이 툭 하고 나타나면, 아무 일도 하지 않은 것이 된다.
그래서 둘 다 시간이 걸리게 했다.

| | 걸리는 일 | 보이는 것 |
|---|---|---|
| 나무 베기 | 도끼질 세 번 (약 1.4초) | 팔을 들어 내리치고, 나무가 휘청이고, 나뭇조각이 튄다 |
| 돌 캐기 | 곡괭이질 네 번 (약 1.6초) | 같은 동작에 돌조각이 튄다 |
| 집 짓기 | 약 1.3초 | 땅이 다져지고 먼지가 일며, 부품이 하나씩 솟아 제자리에 내려앉는다 |

캐는 도중에 멀어지면 중단된다. 붙잡아 두지 않는다.
건설 연출은 시대 변이(morph)가 쓰는 "솟아오르는" 어법을 그대로 빌려 왔다.
거기서는 시간이 건물을 세우고, 여기서는 사람이 세운다.

### 집을 왜 짓는가 — 주민

집 한 채에 사람 하나가 들어와 산다.
그 사람은 11~16초마다 나무나 돌을 하나씩 모아 온다. **손이 늘어난다.**
창고를 지으면 그 간격이 줄어든다.

| 건물 | 드는 것 | 하는 일 |
|------|---------|---------|
| 집 | 나무 3, 돌 1 | 주민 한 사람이 들어온다 (발전도 +10) |
| 창고 | 나무 2, 돌 3 | 주민이 더 자주 날라 온다 (발전도 +12) |
| 망루 | 나무 5, 돌 4 | 지도가 한 번에 넓게 열린다 (발전도 +16) |
| 제단 | 나무 2, 돌 5 | 이정표가 두 번 충전된다 (발전도 +14) |

주민은 시대를 넘어 따라온다. 내 집이 그 자리에 다시 서기 때문이다.
좌측 상단에는 지금 무엇을 하면 되는지가 한 줄로 떠 있고,
건설 메뉴에서 권하는 항목에는 `← 권함` 이 붙는다.

### 내가 지은 것 — 깃대

집마다 깃대가 하나씩 선다. 깃폭은 빛을 받지 않는 재질이라
밤의 조선에서도 같은 밝기로 보인다. 미니맵에서도 금빛 네모로 따로 찍힌다.

### 시간의 문이 열릴 때

발전도가 차면 고인돌에서 빛기둥이 솟고, 하늘에 고리 넷이 차례로 떠오르며,
땅으로 충격파가 퍼진다. 3초 동안만 요란하고 그 뒤에는 조용히 맥박처럼 남는다.

### 상단 자원 표시

가진 것(주민 · 나무 · 돌 · 발전도)은 화면 맨 위 한가운데에 늘 떠 있다.
숫자가 늘어나면 한 번 튀어서, 방금 무엇이 들어왔는지 눈이 잡는다.

### 미니맵

우측 상단에 등각 화면과 같은 방향으로 회전한 지도가 있다.
강과 연못, 건물, 아직 조사하지 않은 유물(깜빡이는 마름모),
시간의 문(원)이 표시된다.

### 이정표

`H` 를 누르거나 버튼을 클릭하면 플레이어 옆에 나무 이정표가 세워지고,
화면 아래에 목표의 방향 · 거리 · 방위가 표시된다.
자동 이동은 하지 않는다. 약 9초 후 사라진다.

### 소리 — 시대별 음계

국악의 5음 음계는 크게 두 갈래다.
**평조(平調)** 는 장5음에 가까워 밝고 트여 있고,
**계면조(界面調)** 는 단5음에 가까워 어둡고 굽이친다.
여섯 시대에 같은 음계를 쓰면 전부 같은 정서가 된다.

| 시대 | 음계 | 악기 | 타악 |
|------|------|------|------|
| 신석기 | 완전4·5도만 (조성 이전) | — | 가죽 북 |
| 청동기 | 계면조 | — | 제의의 겹북 |
| 삼국 | 평조 | 거문고·가야금 (뜯는 소리) | 넓고 낮은 북 |
| 조선 | 계면조 | 대금 (숨소리 섞인 긴 음) | 야경꾼 딱따기 |
| 1970 | 평조 높은 음역 | 라디오 (좁은 대역) | 없음 |
| 2000 | 지속음 둘 | — | 없음 |

신석기에는 "음계"라고 부를 것이 없었다. 그래서 완전음정만 쓴다.
근현대에는 규칙적으로 울리는 북이 없다.

### 날씨와 시간

시대마다 고유한 **시간대 구간**이 있고, 시간은 그 안에서만 아주 천천히 오간다.
(조선이 대낮이 되어 버리면 시대의 인상이 무너지기 때문이다.)

날씨는 1~2분마다 바뀌고 12초에 걸쳐 섞인다. 바뀌는 것은
안개 농도와 색, 햇빛의 세기와 각도, 환경광, 후처리 색보정, 빗줄기와 빗소리다.
좌측 상단에 `맑음 · 늦은 오후` 처럼 표시된다.

기후도 시대마다 다르다. 강가 습지(신석기)와 낙동강 유역(삼국)은 안개가 잦고,
메마른 황토 언덕(청동기)과 한낮의 시골(1970)은 대체로 맑다.
도시(2000)는 맑은 날에도 박무가 걷히지 않는다.

### 배치 규칙 — 강을 조심할 것

강은 화면 좌표로 `v > 7.6` 인 영역을 흐른다. 그 위에는 **육지가 없다.**
배치하는 v 가 이 선을 넘으면 건물이 강물 위에 서고, 유물은 집을 수 없게 된다.

근현대 두 시대는 `P` 자체가 v 를 육지 범위로 눌러 넣는다.
배치 코드는 읽기 쉬운 값을 그대로 쓰고, 압축은 한 곳에서만 일어난다.

```js
const P = (u, v) => S(u, v * 0.725 - 9.5);
```

다리처럼 일부러 강을 건너야 하는 것은 압축하지 않은 `S` 를 쓴다.

### 밀도

여섯 시대 모두 화면 좌표로 배치하고, 오브젝트를 화면 전체에 채운다.
건물 하나하나는 단순해도 여러 개가 모이면 사람이 살던 자리처럼 보인다.

### 화면 좌표 배치

등각 고정 시점이라 마을 배치는 월드 좌표가 아니라 **화면 좌표**로 잡는다.
`S(u, v)` 는 화면에서의 위치(오른쪽 u, 위쪽 v)를 월드 좌표로 바꿔 준다.
화면에 들어오는 범위는 대략 `u ∈ [-26, 26]`, `v ∈ [-25, 25]` 이다.
(세로는 등각 때문에 눌려 보이므로 `v` 를 더 크게 잡아야 화면이 찬다.)

### 시대 변이

시대가 바뀔 때 장면을 통째로 갈아 끼우지 않는다.
빛의 경계선이 화면을 왼쪽에서 오른쪽으로 쓸고 지나가면서,
그 선을 넘은 건물부터 하나씩 다음 시대의 모습으로 솟아오른다.
두 시대가 잠시 한 화면에 공존한다.

강의 위치, 큰 바위, 고인돌 자리(`GATE_SPOT`)는 **모든 시대가 공유한다**.
신석기에서 본 그 바위를 다음 시대에서 다시 만나게 된다.
삼국시대의 토성은 바로 그 자리에서만 바깥으로 꺾여 돌아간다.

## 기술

- **단일 `index.html`** — 외부 에셋 없음. `file://` 로 직접 열어도 실행된다.
- **Three.js** (CDN) — 모든 3D 모델을 기본 geometry 조합으로 코드에서 생성
- **저해상도 렌더 타겟** → 후처리 셰이더 → CSS `image-rendering: pixelated` 확대
- **후처리 셰이더** — 세피아 그레이딩, 4x4 Bayer 디더링, 필름 그레인, 비네팅, 색수차, 종이 질감, 시대 전환 글리치
- **Web Audio API** — 바람 · 물소리 · 북 · 국악 5음 음계 선율 · 환경음을 시대별로 전부 합성 (음원 파일 없음)

## 실행

```bash
# 그냥 파일을 열어도 된다
open index.html

# 또는 로컬 서버
python3 -m http.server 8000
```

게임은 언제나 신석기 빈 들판에서 시작한다.
개발 중에는 `index.html?era=1` / `?era=2` 로 특정 시대부터,
`?era=prologue` 로 옛 현대 프롤로그(밤 귀갓길)를 볼 수 있다.
`?seed=` 로 자연 지형을 고정할 수 있다.

## 배포 (Vercel)

정적 사이트이므로 빌드 과정이 없다.

```bash
vercel --prod
```

또는 GitHub 저장소를 Vercel 에 연결하면 푸시할 때마다 자동 배포된다.
Framework Preset 은 **Other**, Build Command 와 Output Directory 는 비워 둔다.

## 코드 구조

`index.html` 안의 스크립트는 다음 순서로 나뉘어 있다.

```
GAME STATE        시대 정의 (색 / 조명 / 안개 / 능선 / 그레이딩)
AUDIO             Web Audio 합성, 시대별 사운드 설정표
NOISE / TERRAIN   value noise, fbm, 지형 높이, 절차적 텍스처
POST PROCESSING   저해상도 렌더 타겟 + 90년대 느낌 셰이더
THREE INIT        렌더러 / 등각 카메라
INPUT             키보드 / 마우스
MATERIAL HELPERS  기본 도형 조합 헬퍼
UI / INTERACTION  조사, 인벤토리, 메시지
PLAYER            로우폴리 인물 + 걷기 애니메이션
CAMERA            고정 등각 추적
WORLD             지면, 배경판, 안개, 먼지, 풀, 길, 연못
MINIMAP / HINT    미니맵, 이정표
ERA BUILD         시대별 장면 구성
```

### 렌더링에서 신경 쓴 것

- **직교 카메라의 스펙큘러** — 시선 방향이 화면 전체에서 같기 때문에 매끈한 수면은
  판 전체가 균일하게 하얗게 타버린다. 물은 일부러 거칠게(`roughness` 0.8 이상) 두고,
  반짝임은 발광 판과 잔물결로 따로 만든다.
- **텍스처 이중 감산** — 오브젝트 텍스처는 재질의 `color` 와 곱해지므로 거의 흰 바탕에
  어두운 결만 그린다. 색을 가진 텍스처는 지면용 하나뿐이다.
- **인스턴싱** — 풀 · 자갈 · 논의 모 · 텃밭 잎 · 돌담 · 목책 · 토성처럼
  같은 모양이 수백 개씩 반복되는 것은 `InstancedMesh` 로 묶는다.
- **지오메트리 공유** — 상자 하나마다 `BufferGeometry` 를 새로 만들면 한 시대에
  2만 개 가까이 쌓인다. "단위 크기" 도형 하나를 만들어 두고 `mesh.scale` 로 크기를 준다.
  공유 지오메트리는 시대가 바뀌어도 버리지 않는다 (`geometry.userData.shared`).
- **시대 전환 정리** — 이전 시대의 월드 · 배경판 · 플레이어 · 태양광(그림자 깊이 텍스처) ·
  구운 텍스처를 전부 버린다. 재질을 타고 내려가는 정리만으로는
  그 시대에 쓰이지 않은 텍스처와 조명의 그림자 맵이 잡히지 않는다.

시대별 색감은 `AGE_DATA`, 질감 팔레트는 `TEX_PALETTE`, 사운드는 `AudioSystem.ERA_SOUND` 에서 한 곳에 모아 조정할 수 있다.
