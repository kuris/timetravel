# 시간유적 (Time Ruins)

한반도의 같은 강가를 **여섯 시대가 나눠 쓴다**. 그 땅 위를 걸어 다니며
유물과 흔적을 조사하고, **시간의 문으로 시대를 건너는** 어드벤처.

> 삼국시대 성돌에 새겨진 이름이, 2000년 발굴 보고서에 다시 나온다.

전투는 없다. 체력도 없다. 들개가 내려오지만 싸우지 않는다 — 불을 피워 막을 뿐이다.

## 지금 어디까지 와 있나

RTS(Age of Empires 식)로 한 번 갈아엎었던 것을 **되돌려**, 다시 걸어 다니는
어드벤처로 왔다. RTS 코드는 지우지 않고 `rts-backup` 브랜치에 남겨 두었다.

- 시작 시대는 **삼국**이다 (`START_AGE = 2`). 신석기와 청동기는 이 이야기의 "그 전"이라,
  단서가 그리로 데려갈 때 열린다
- 시대는 **앞으로도 뒤로도** 간다. 가진 것과 알아낸 것은 따라온다
- 1인칭과 3인칭은 `V` 로 **언제든** 바뀐다

아직 없는 것은 아래 [남은 일](#남은-일)에 적어 두었다.

## 컨셉

1997년에 나온 한국사 CD-ROM 교육용 PC 게임을 2026년에 웹으로 다시 만든 것 같은 화면.

- **Day of the Tentacle** — 한 장소를 여러 시대가 공유하고, 과거에서 한 일이 미래에 남는다
- **Back to the Future** — 시대를 오가는 인과
- **Age of Empires 1** — 고정 등각 시점, 작은 캐릭터와 넓은 세계
- **대항해시대 (KOEI)** — 황동 테두리의 장식적인 UI

## 여섯 시대

| # | 시대 | 배경 | 조사 대상 |
|---|------|------|-----------|
| 0 | 신석기 | 한반도 강가 빈 땅 | 빗살무늬 토기 조각 · 간석기 · 불탄 나무 조각 |
| 1 | 청동기 | 고인돌 제단과 논 | 비파형 동검 조각 · 청동 방울 · 제단 문양 |
| **2** | **삼국** ← 시작 | 낙동강 유역 토성 | 명문 기와 · 목간 · 성벽 각자 |
| 3 | 조선 | 한양 외곽 마을 (해질녘) | 어사패 · 낡은 문서 · 장승의 문양 |
| 4 | 1970 | 시골 마을 | 공사 기록 · 낡은 수첩 · 멈춘 공사 |
| 5 | 2000 | 한강변 신도시 (초저녁) | 발굴 보고서 · 발굴 구덩이 · 안내판 |

### 여섯 시대가 같은 땅을 쓴다

이 게임이 시간 여행물일 수 있는 이유는 전부 이 한 가지에서 나온다.

강의 자리, 큰 바위, 자갈과 풀의 자리는 `generateBaseMap(seed)` 가 **한 판에 한 번만**
정하고, 시대는 그것을 자기 색으로 칠하기만 한다. 신석기에서 본 그 바위를
2000년대 아파트 화단에서 다시 만난다.

시간의 문이 서는 자리(`GATE_SPOT`)도 여섯 시대 모두 같은 좌표다 — `{ x: 17.0, z: -11.3 }`.
어느 시대에서 문에 들어서든, 나오는 자리는 같은 땅의 같은 지점이다.

`?seed=` 로 땅을 고정할 수 있다.

### 시대를 건너는 것 / 건너지 못하는 것

| 시대를 건넌다 | 시대마다 새로 | 
|---|---|
| 인벤토리 (`G.inventory`) | 장면 · 지형의 색 · 하늘 · 소리 |
| 단서 (`G.clues`) | 그 시대의 NPC와 재료 노드 |
| 조사 기록 (`G.investigated`) | 전장의 안개 (`G.exploredTiles`) |
| 일지 (`G.journal`) | 이정표 3회 (`G.hintCharges`) |
| 내가 지은 마을 (`G.village`) | |
| 인과 선택 (`G.fateChoice`) | |

삼국에서 주운 목간을 2000년 발굴 구덩이로 가져갈 수 있어야 하므로,
인벤토리와 단서는 `buildAge` 에서 **절대 비우지 않는다**.

조사 기록은 `"시대index:유물이름"` 으로 저장된다. 그래서 삼국에 다시 돌아오면
전에 조사한 성돌은 조사된 채로 서 있다.

## 조작

| 입력 | 하는 일 |
|------|---------|
| `WASD` · 방향키 | 이동 (`Shift` 로 달리기) |
| `E` | 조사 · 획득 · 사용 |
| `V` | **1인칭 / 3인칭 전환 (언제든)** |
| `T` · `Y` | 시간 / 날씨 조절 |
| `H` | 이정표 (방향 안내, 시대마다 3회) |
| `J` | 탐험 일지 |
| 마우스 클릭 | 이동 / 시선 고정 |

## 기술

- **외부 에셋 없음.** 모든 3D 모델은 기본 도형 조합으로 코드에서 만든다
- **Three.js** (CDN) — 고정 등각 직교 카메라
- **저해상도 렌더 타겟 → 후처리 셰이더 → CSS `image-rendering: pixelated`**
  (그레이딩 · 4×4 Bayer 디더링 · 필름 그레인 · 비네팅 · 종이 질감)
- **Web Audio API** — 바람 · 물 · 북 · 5음 음계 선율을 전부 합성 (음원 파일 없음)
- 시대 전환은 장면을 갈아 끼우지 않는다. 빛의 경계선이 화면을 쓸고 지나가면서
  건물이 하나씩 다음 시대의 모습으로 바뀐다 (`morph.js`, 3.4초)

## 남은 일

이 방향으로 오면서 아직 채우지 못한 것들.

- **사람이 없다.** RTS 로 갈아엎을 때 각 시대에서 NPC 를 들어냈다.
  삼국시대에 지금 사람이 한 명도 없다 (`samguk.js` 의 "이 시대에도 사람은 두지 않는다")
- **동사가 하나뿐이다.** `E` 하나로 조사 · 획득 · 사용을 다 한다
- **아이템을 조합할 수 없다.** `G.inventory` 는 담기만 한다 — "A 를 B 에 쓴다" 가 없다
- **인과가 하나뿐이다.** `G.fateChoice` (청동기 제단 선택) 하나. 과거에서 한 일이
  미래를 바꾸는 연결이 더 있어야 한다
- **진급 조건이 아직 마을 발전도다.** `handleAgeCompletion()` 이 `G.progress` 를 본다

## 실행

```bash
open index.html          # 그냥 열어도 된다
python3 -m http.server 8000
```

`?era=0`~`5` 로 시대를 바로 열 수 있고, `?era=prologue` 로 프롤로그를 본다.
콘솔에서는 `TR.G` 로 상태를, `TR.travel(3)` 으로 시대 이동을 시험할 수 있다.
