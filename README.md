# 시간유적 (Time Ruins)

한국사 여섯 시대를 **시대(Age)** 로 삼은 **실시간 전략** 게임.
Age of Empires 1 의 단일 플레이를 그대로 한반도의 강가로 옮겼다.

> 같은 강가에서 두 마을이 일어선다. 모으고, 짓고, 싸우고, 시대를 연다.

## 한눈에

| | |
|---|---|
| 장르 | 실시간 전략 (RTS) · 1 대 1 단일 플레이 |
| 시점 | 고정 등각(Isometric). 화면 가장자리와 방향키로 훑는다 |
| 자원 | 식량 · 나무 · 돌 · 금 |
| 시대 | 신석기 → 청동기 → 삼국 → 조선 → 1970 → 2000 (여섯) |
| 이기는 법 | 적의 건물과 유닛을 전부 없앤다 |
| 지는 법 | 내 건물과 유닛이 전부 사라진다 |

## 조작 — Age of Empires 와 같다

**자판은 거들 뿐이다.** 마우스만으로도, 손가락만으로도 처음부터 끝까지 할 수 있다.

### 마우스

| 입력 | 하는 일 |
|------|---------|
| 왼쪽 클릭 | 고르기 |
| 왼쪽 끌기 | 상자 선택 (병사가 섞이면 병사만 고른다) |
| 같은 대상 두 번 클릭 | 화면 안의 같은 종류 전부 |
| 오른쪽 클릭 | 상황에 맞는 명령 — 가기 · 캐기 · 치기 · 짓기 · 고치기 |
| 오른쪽 클릭 (건물 하나 고른 상태) | 집결점 |
| 화면 가장자리 | 시점 이동 |
| 휠 | 확대 · 축소 (지도 옆 `－` `＋` 도 같다) |
| 미니맵 클릭 · 끌기 | 그 자리로 이동 / 오른쪽 클릭은 이동 명령 |
| 위쪽 [회관] [노는 주민] [사건] [안내] [1인칭] | 마을회관 · 노는 주민 · 마지막 사건 · 튜토리얼 · 1인칭 |
| 왼쪽 아래 부대 칸 `1`~`4` | 빈 칸이면 묶고, 찬 칸이면 부른다. 길게 누르거나 오른쪽 클릭하면 다시 묶는다 |
| 초상 옆 `✕` | 선택 해제 |

### 손가락 (전화기 · 태블릿)

| 입력 | 하는 일 |
|------|---------|
| 톡 | 내 것이면 고르기. 고른 것이 있으면 그 자리가 곧 명령 |
| 두 번 톡 | 화면 안의 같은 종류 전부 |
| 끌기 | 지도를 끌어 시점 이동 |

| 지도 · 명령 칸 · 위쪽 단추 | 마우스와 같다 |

좁은 화면에서는 조작판이 줄고, 미니맵이 오른쪽 위로 올라간다.
안내 칸은 제목 줄을 누르면 접힌다. 안내 칸 아래의 땅도 그대로 눌린다.

## 유닛

| 유닛 | 나오는 곳 | 시대 | 드는 것 | 특징 |
|------|-----------|------|---------|------|
| 주민 | 마을회관 | 신석기 | 식량 50 | 모으고 짓고 고친다 |
| 몽둥이병 | 병영 | 신석기 | 식량 50 | 가장 오래된 병사 |
| 도끼병 | 병영 | 청동기 | 식량 60 · 나무 20 | 청동 날 |
| 창병 | 병영 | 삼국 | 식량 70 · 나무 25 | 줄지어 막는다 |
| 기병 | 병영 | 조선 | 식량 90 · 금 20 | 빠르게 돌아 들어간다 |
| 궁수 | 활터 | 청동기 | 식량 60 · 나무 30 | 멀리서 쏜다 |
| 쇠뇌수 | 활터 | 조선 | 식량 70 · 나무 40 | 한 발이 무겁다 |

주민은 챙 넓은 짚모자에 짚빛 옷, 병사는 투구 위에 진영색 뿔을 세운다.
발밑 원판도 다르다 — 병사만 테를 두른다. 멀리서도 일꾼과 싸움꾼이 갈린다.

들판에는 사슴과 멧돼지가 있다. 사슴은 달아나고, 멧돼지는 건드리면 달려든다.
쓰러뜨리면 그 자리가 식량이 된다.

## 건물

| 건물 | 드는 것 | 하는 일 |
|------|---------|---------|
| 마을회관 | 나무 200 · 돌 100 | 주민을 뽑고 **시대를 연다**. 모든 자원을 내려놓는다 (인구 +4) |
| 집 | 나무 30 | 인구 상한 +4 |
| 곡식창고 | 나무 120 | 식량을 내려놓는 곳 |
| 저장고 | 나무 120 | 나무 · 돌 · 금을 내려놓는 곳 |
| 농장 | 나무 75 | 주민이 식량 250 을 거둔다. 다 거두면 사라진다 |
| 병영 | 나무 125 | 근접 병사 |
| 활터 (청동기~) | 나무 150 | 활을 쏘는 병사 |
| 망루 (청동기~) | 돌 150 | 다가오는 적을 스스로 쏜다. 멀리 본다 |
| 성벽 (청동기~) | 돌 5 | 한 칸씩 세워 길을 막는다 |

인구 상한은 50 이다. 마을회관과 집이 각각 4 씩 받쳐 준다.
그래서 시작하자마자 집부터 지어야 한다 (AoE 1 과 같다).

## 튜토리얼

시작 화면에서 **[튜토리얼]** 을 고르면, 지금 그 판 위에서 열두 걸음을 일러 준다.
따로 판을 만들지 않는다 — 안내를 끄면 그대로 이어서 하던 판을 한다.

| | 걸음 | 해내야 하는 것 |
|---|------|----------------|
| 1 | 강가를 둘러본다 | 시점 옮기기 |
| 2 | 주민을 고른다 | 주민 하나 고르기 |
| 3 | 나무를 벤다 | 오른쪽 클릭으로 캐게 하기 |
| 4 | 여럿을 한꺼번에 | 상자로 둘 이상 고르기 |
| 5 | 먹을 것을 모은다 | 식량 캐기 |
| 6 | 집을 짓는다 | 집 자리 잡기 |
| 7 | 주민이 걸어와 짓는다 | 집 완성 |
| 8 | 주민을 더 뽑는다 | 주민 뽑기 |
| 9 | 병영을 세운다 | 병영 완성 |
| 10 | 병사를 뽑는다 | 병사 하나 뽑기 |
| 11 | 부대로 묶는다 | `Ctrl`+`1` |
| 12 | 시대를 연다 | 시대 발전 누르기 |

걸음마다 마우스로 하는 법과 손가락으로 하는 법이 따로 적힌다 (지금 쓰는 입력을 따라간다).
안내는 규칙을 건드리지 않는다. 매 프레임 판을 들여다보며 "해냈는가"만 묻는다.
그래서 순서를 앞질러 해 두었으면 그 걸음은 저절로 지나간다. 걸음마다
[이 걸음 건너뛰기] 가 있고, `F1` 로 언제든 열고 닫는다.

가리키는 것은 두 가지다. 땅 위에는 황동빛 **화살표**(그 나무, 그 주민)가 서고,
아래 명령 칸에서는 눌러야 할 칸이 **깜빡인다**. 가리킬 것이 화면 밖이면
그 걸음에 들어설 때 한 번만 시점을 옮겨 준다.

**안내가 도는 동안에는 적이 쳐들어오지 않는다.** 적은 그동안에도 모으고 짓는다.
안내가 끝나면 45초쯤 뒤부터 다시 떼가 온다.

## 1인칭 — 내려다보지 않고 서 본다

`V` 를 누르면(또는 위쪽 [1인칭] 단추) 등각 시점에서 내려와 그 땅에 선다. **언제든 된다.**
고른 것이 있으면 그 곁에, 없으면 지금 보고 있는 자리에 선다.

판은 그대로 돌아간다. 주민은 계속 나무를 베고, 적은 계속 온다.
다만 명령은 내릴 수 없다 — 눈만 있다. 다시 `V` (또는 `Esc` · [나가기]) 로 올라온다.

| 입력 | 하는 일 |
|------|---------|
| 마우스를 움직이거나 끌기 | 둘러보기 (포인터 락이 걸리면 그냥 움직이면 된다) |
| 왼쪽 단추를 누르고 있기 | 앞으로 걷기 (오른쪽은 뒤로) |
| `W` `A` `S` `D` · 방향키 | 걷기 (`Shift` 로 빠르게) |
| 손가락으로 끌기 | 둘러보기 |
| 아래 [앞으로] [뒤로] | 누르고 있는 동안 걷는다 |

전화기에서는 위쪽 **[1인칭]** 단추로 들어간다. 자판이 없어도 된다 —
둘러보기는 끌기, 걷기는 화면 아래 단추, 나가기는 [나가기].

물과 판 밖, 건물 안으로는 들어가지 못한다. 마을회관 한가운데에서 내려서면
갇히지 않도록 바깥으로 한 걸음 밀어 놓는다.

**전장의 안개는 여기서도 규칙대로다.** 안 보이는 적은 1인칭에서도 보이지 않는다.
시대가 올라 땅과 하늘이 바뀌어도 서 있던 자리는 그대로다.

## 시대를 연다 — 이 게임만의 것

마을회관에서 **시대 발전**을 누르면 32초 뒤 다음 시대가 열린다.
조건은 AoE 와 같다. **건물 셋 이상**과 값(식량, 시대가 오를수록 금도).

| 다음 시대 | 드는 것 |
|-----------|---------|
| 청동기 | 식량 400 |
| 삼국 | 식량 600 · 금 150 |
| 조선 | 식량 800 · 금 300 |
| 1970 | 식량 1000 · 금 450 |
| 2000 | 식량 1200 · 금 600 |

AoE 에서는 건물의 생김새만 바뀐다. 여기서는 **땅과 하늘과 소리까지** 바뀐다.
화면이 한 번 번쩍이고 나면, 내 움집은 청동기 집이 되고 강가의 빛도 달라진다.
유닛도 건물도 자리를 지킨 채 시간만 지나간다.

| 시대 | 집 | 마을회관 | 하늘 |
|------|-----|----------|------|
| 신석기 | 움집 | 큰 움집 | 맑은 한낮 |
| 청동기 | 청동기 집 | 큰 청동기 집 | 황토빛 늦은 오후 |
| 삼국 | 기와 없는 집 | 기와집 | 낙동강의 박무 |
| 조선 | 초가 | 기와집 | 해질녘 |
| 1970 | 슬레이트 집 | 마을 상회 | 마른 한낮 |
| 2000 | 아파트 | 상가 건물 | 초저녁 도시 |

## 적

적(빨강)은 속이지 않는다. 같은 값을 치르고 같은 속도로 모은다.
다만 쉬지 않는다.

- 주민을 몫에 맞춰 식량 · 나무 · 돌 · 금에 붙인다
- 인구가 차기 전에 집을 한 채씩 올린다
- 곡식창고 → 저장고 → 병영 → 활터 순으로 짓는다
- 시대를 열 값을 모으는 동안에는 병사를 적게 뽑고 참는다
- 떼가 모이면 가장 가까운 내 건물로 쳐들어온다. 물결은 갈수록 커진다
- 내 마을 가까이 적이 오면 하던 일을 놓고 막으러 온다

## 전장의 안개

지나간 땅은 기억하고, 지금 보이는 땅만 실시간으로 보인다.
적 유닛은 **지금 보이는 곳**에서만 보이고, 건물은 한 번 본 자리를 기억한다.
미니맵은 이 셋(모르는 땅 · 지나간 땅 · 보이는 땅)을 색으로 나눈다.

## 무엇이 무엇인지

이 화면은 낡은 CRT 를 흉내 내느라 온통 세피아다. 그 안에서 서로를 가려내야 한다.

- **건물** — 지붕 위에 글자 한 자가 뜬다 (회 · 집 · 곡 · 저 · 농 · 병 · 활 · 망). 시대마다
  모양이 통째로 바뀌는 게임이라, 움집 셋이 나란히 서면 글자 말고는 알 길이 없다
- **주민과 병사** — 짚모자와 짚빛 옷 / 투구와 진영색 뿔. 병사는 한 뼘 더 크고 발밑에 테가 있다
- **자원** — 덤불 · 돌 · 금 위에는 색깔 마름모가 뜬다 (붉은빛 · 흿빛 · 금빛).
  숲은 빽빽해서 달지 않는다. 열매도 크고 붉게 키워 두었다
- **진영** — 발밑 원판과 깃발이 파랑(나)과 빨강(적)을 말한다

## 땅

여섯 시대가 **같은 땅**을 쓴다. 강의 자리, 큰 바위, 자갈과 풀의 자리는
한 판에 한 번만 정해지고, 시대는 그것을 자기 색으로 칠하기만 한다.
신석기에서 본 그 바위를 2000년대에 다시 만난다.

강은 화면 위쪽으로 흐른다. 그 위에는 아무도 서지 못한다.
`?seed=` 로 땅을 고정할 수 있다.

## 소리

시대마다 음계가 다르다. 평조(밝고 트인 장5음)와 계면조(어둡고 굽이치는 단5음)를
시대에 따라 갈라 쓴다. 신석기에는 아직 "음계"라고 부를 것이 없어 완전음정만 쓴다.

| 시대 | 음계 | 악기 |
|------|------|------|
| 신석기 | 완전4·5도 | 가죽 북 |
| 청동기 | 계면조 | 제의의 겹북 |
| 삼국 | 평조 | 거문고 · 가야금 |
| 조선 | 계면조 | 대금 · 딱따기 |
| 1970 | 평조 높은 음역 | 라디오 |
| 2000 | 지속음 둘 | — |

손가락으로 하면 처음 시야가 한 뼘 더 가깝다 (작은 화면에서 유닛을 집으려면 커야 한다).

## 기술

- **외부 에셋 없음.** 모든 3D 모델은 기본 도형 조합으로 코드에서 만든다
- **Three.js** (CDN) — 고정 등각 직교 카메라
- **저해상도 렌더 타겟 → 후처리 셰이더 → CSS `image-rendering: pixelated`**
  (세피아 그레이딩 · 4×4 Bayer 디더링 · 필름 그레인 · 비네팅 · 색수차 · 종이 질감)
- **Web Audio API** — 바람 · 물 · 북 · 5음 음계 선율을 전부 합성 (음원 파일 없음)
- 유닛 고르기는 레이캐스트가 아니라 **화면 좌표 투영**으로 푼다. 등각 고정 시점이라
  월드 좌표를 화면으로 던지는 편이 싸고 정확하다

## 코드 구조

```
js/
  main.js            진입점 — 판을 만들고 루프를 돈다
  rts/
    defs.js          규칙표 (유닛 · 건물 · 시대 비용 · 진영 색)
    state.js         R — 한 판의 상태 (규칙의 세계)
    map.js           판 만들기 — 지형, 자원, 두 진영의 시작
    units.js         유닛의 상태 기계 (이동 · 채집 · 건설 · 전투)
    buildings.js     배치 · 건설 · 생산 · 인구 · 시대 발전
    combat.js        화살
    ai.js            적 진영
    fog.js           전장의 안개
    control.js       마우스 · 손가락 · 자판, 명령 칸 목록
    input.js         지금 무엇으로 조작하는가 (마우스인가 손가락인가)
    fpv.js           1인칭 — 그 땅에 서서 둘러보기 (V)
    hud.js           조작판과 미니맵
    tutorial.js      첫 판을 위한 안내 (열두 걸음)
    rtscam.js        훑는 카메라
    age.js           시대가 오르는 순간 (장면을 다시 짓는다)
    models.js        사람 · 짐승 · 자원 · 병영 · 활터 · 성벽 모형
    nodes.js         땅에 있는 자원
    loop.js          한 프레임
  eras/              시대별 건물 모형 (움집 · 기와집 · 아파트 ...)
  world.js  basemap.js  landmarks.js  terrain.js  palette.js  textures.js
  audio.js  weather.js  postprocess.js  renderer.js  build.js
```

`G` 는 보이는 세계(three.js), `R` 은 규칙의 세계다.
시대가 올라 장면을 통째로 다시 지어도 `R` 은 그대로 살아남는다.

## 실행

```bash
# 그냥 파일을 열어도 된다
open index.html

# 또는 로컬 서버
python3 -m http.server 8000
```

개발 중에는 콘솔에서 `RTS.simulate(120)` 으로 판을 빨리 굴려 볼 수 있다.
`RTS.R` 에 한 판의 상태가 전부 들어 있다.

## 배포 (Vercel)

정적 사이트이므로 빌드 과정이 없다.

```bash
vercel --prod
```

또는 GitHub 저장소를 Vercel 에 연결하면 푸시할 때마다 자동 배포된다.
Framework Preset 은 **Other**, Build Command 와 Output Directory 는 비워 둔다.
